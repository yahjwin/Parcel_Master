# 📦 Parcel Master

Unity로 개발한 2D 택배 업무 체험 게임입니다.  
플레이어는 월드를 탐색하며 택배 회사에 입장하고,
택배 분류와 배송을 주제로 한 두 가지 미니게임을 순차적으로 플레이합니다.

## 🎮 Game Overview

- **Engine** : Unity
- **Language** : C#
- **Genre** : 2D / Mini Game
- **Play Mode** : Single Player

## 🕹️ Gameplay

### Stage 1. 택배 분류

위에서 무작위로 등장하는 택배를 종류에 맞게 분류하는 미니게임입니다.

- 다양한 종류의 택배 랜덤 생성
- 택배 종류에 따른 분류 시스템
- 정답/오답 판정
- 연속 정답에 따른 콤보 시스템

### Stage 2. 배송

도로를 달리는 택배 트럭을 조작하여
여러 차선에서 등장하는 차량을 피하는 미니게임입니다.

- 차량 랜덤 생성
- 플레이어 트럭 이동
- 차량과의 충돌 판정
- 체력 시스템
- 제한 시간 시스템

## ✨ Main Features

- 2D 월드 및 캐릭터 이동
- 건물 입장을 통한 게임 진행
- Scene 전환을 활용한 단계별 게임 구성
- Random 요소를 활용한 오브젝트 생성
- Collision을 활용한 충돌 및 판정 시스템
- UI를 통한 체력, 시간, 게임 상태 표시
